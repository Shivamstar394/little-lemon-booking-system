
# Little Lemon Booking System

This project is a mock implementation of a database booking system for the Little Lemon restaurant.

## Contents

- `littlelemon_schema.sql`: SQL file to create tables
- `procedures.sql`: SQL stored procedures
- `python_scripts/run_procedures.py`: Python script to connect and execute procedures
- `ER_Diagram.png`: Entity Relationship diagram
- `tableau/LittleLemon_Analysis.twbx`: Tableau Workbook (dummy)
- `tableau/dashboard_screenshot.png`: Sample dashboard screenshot

## Instructions

1. Import `littlelemon_schema.sql` into your MySQL server.
2. Run `procedures.sql` to create stored procedures.
3. Modify the `python_scripts/run_procedures.py` script with your DB credentials and run it.
4. Open the Tableau workbook to see visualized reports.
